## Usage
1. Run Counter-Strike 1.6
2. Open `cheat.exe`

4. Enjoy :)

- Visual Studio 2015 or higher

## Compilation
1. Open `CS16AutoBhop.sln`
2. Set platform to Win32 (x86)
